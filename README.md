Torre de hanoi

Metodos implementados en el programa 
## Metodos utilizados

El programa tiene 3 metodos:

- torre_hanoi(): Se encarga de hacer los movimientos de los discos entre las torres.
- convertir_tiempo(): Sirve para convertir el tiempo de segundos a minutos, horas, dias o anos.
- main(): Es donde se ejecuta el programa. Aqui se prueban las cantidades de 5, 10, 30 y 64 discos y se muestran los resultados.

En total, el programa utiliza 3 metodos.

 Conclusiones

Con este programa aprendi como funciona la Torre de Hanoi y como se pueden mover los discos siguiendo un orden. 
Tambien aprendi a usar funciones en Python y a medir el tiempo que tarda el programa en ejecutarse.
Al probar diferentes cantidades de discos, pude observar que los movimientos aumentan demasiado conforme se agregan mas discos. 
Por ejemplo, con 5 discos son 31 movimientos, pero con 64 discos son mas de 18 trillones de movimientos.
Esto me permitio entender que algunos problemas pueden ser faciles de resolver con pocos datos, 
pero al aumentar la cantidad de datos pueden necesitar mucho mas tiempo para completarse.
